Add `dievas` to a Flutter application.

Add `dievas_tokens` separately when you import its pure Dart values or brand palettes.

import { Steps } from "@astrojs/starlight/components";

## Before you begin

Use a Flutter SDK that includes Dart **3.11.4 or later**, below Dart 4. The package also declares Flutter >=3.22.0; meeting that Flutter minimum alone does not guarantee a compatible Dart SDK.

<Steps>

1. Check the Dart version bundled with your Flutter installation:

    ```sh
    flutter --version
    ```

    Confirm the reported Dart version meets the requirement.

2. From your application's directory, add the documented release:

    ```sh
    flutter pub add dievas:^1.0.4
    ```

    For palette or token imports, also add:

    ```sh
    flutter pub add dievas_tokens:^1.0.3
    ```

3. Import the public Flutter library:

    ```dart
    import 'package:dievas/dievas.dart';
    ```

    Avoid imports from `package:dievas/src/`.

    Internal paths can change independently of the public API.

</Steps>

## Confirm the dependency resolution

Inspect the resolved versions:

```sh
flutter pub deps --style=compact
```

Confirm `dievas` and `dievas_tokens` appear.

Dievas 1.0.4 requires tokens ^1.0.3. If dependency solving fails, check your SDK and explicit package constraints before adding overrides.

## Use tokens without Flutter

For a Dart CLI, server, or Jaspr application, install only the token package:

```sh
dart pub add dievas_tokens:^1.0.3
```

The token library contains no Flutter dependency. See [Use semantic tokens](/foundations/tokens/).
