## How the pieces fit

<CardGrid>
  <Card title="Tokens" icon="setting">`dievas_tokens` provides primitive values and semantic roles without importing Flutter.</Card>
  <Card title="Themes and components" icon="puzzle">`dievas` converts tokens into Flutter themes and reusable widgets.</Card>
  <Card title="Interactive gallery" icon="open-book">Widgetbook lets you inspect component variants, themes, and states.</Card>
  <Card title="Your application" icon="rocket">You own state, navigation, validation, and product behaviour.</Card>
</CardGrid>

## Documentation baseline

These guides target Dievas **1.0.4** and tokens **1.0.3**. Examples use the public package imports. The [upgrade guide](/maintain/upgrade/) explains naming migrations; the [API reference](/maintain/reference/) links to exact versioned declarations.
