Choose a component by the task it supports. This inventory lists the exported component widgets in the reviewed source. Public helper, controller, theme, and enum declarations are covered by the [API reference](/maintain/reference/).

## Before you compose components

Install the [theme root](/theming/scope/) and import `package:dievas/dievas.dart`. Your application owns state, data fetching, routing, and validation.

## Guide coverage

Detailed guides cover buttons, text inputs, selection controls, feedback, and modal/sheet workflows. A linked family guide covers the components named in that guide; other widgets retain API/gallery coverage without a dedicated usage guide. The inventory does not imply all components have the same documentation depth.

## Inspect components interactively

Open the [Widgetbook gallery](https://master.dievas-gallery.pages.dev) and select the component. Compare the available variants and controls. The gallery may track repository changes newer than the package version; consult the versioned API links in this inventory.

## Contribute a guide

Use the [documentation contribution contract](/maintain/contributing/) to add a verified component page. Explain state ownership and integration before listing every property.
